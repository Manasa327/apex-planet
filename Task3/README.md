# Weather App - ApexPlanet Task 3

## About

This is a simple Weather App created for the ApexPlanet Web Development Internship Task 3.

The application uses JavaScript to fetch real-time weather data from a public API and display it on a webpage.

## Technologies Used

- HTML
- CSS
- JavaScript
- Fetch API
- Open-Meteo API

## Features

- Search weather by city
- Display temperature
- Display humidity
- Display wind speed
- Display weather code
- Error handling
- Simple responsive design

## How It Works

1. User enters a city name.
2. JavaScript sends the city to the Geocoding API.
3. The API provides latitude and longitude.
4. JavaScript requests weather data.
5. The Weather API returns the data.
6. JavaScript displays the data on the webpage.

## Project Structure

Task-3-Weather-App

## How to Run

1. Open the project in VS Code.
2. Open index.html using Live Server.
3. Enter a city name.
4. Click Search.
5. Weather information will be displayed.

## API

This project uses the Open-Meteo API.

No API key is required.
